# 🛒 Amazon Clone - HTML & CSS

A frontend **Amazon Clone website** created using **HTML5 and CSS3**. This project recreates the look and layout of an Amazon-style e-commerce homepage using structured HTML, CSS styling, and image assets.

> **Note:** This project is created for educational and frontend practice purposes. It is not affiliated with or an official version of Amazon.

---

## 📌 About the Project

The **Amazon Clone** is a static frontend website designed to practice website layout, styling, positioning, and responsive frontend concepts.

The project focuses on recreating the visual structure of an e-commerce website, including a navigation area, hero section, product/category boxes, and other homepage elements.

---

## ✨ Features

* 🏠 Amazon-inspired homepage layout
* 🔝 Navigation/header section

## 🚀 How to Run the Project

### Method 1 — Directly in Browser

1. Download or clone the repository.
2. Open the project folder.
3. Double-click `index.html`.
4. The website will open in your browser.

### Method 2 — Using VS Code

1. Open the project in **Visual Studio Code**.
2. Open `index.html`.
3. Install the **Live Server** extension if you don't already have it.
4. Right-click `index.html`.
5. Select **Open with Live Server**.
